Clearify — Analysis Weights & Scoring

How the credibility score and the four bias dimensions are produced, judged, and displayed · v1.0.0   2026-10-20 · verified against source

Every score you see in the Clearify side panel comes from a single AI judgment call, not from a formula computed in extension code. This document gives the exact anchors the model is told to score against, the only numbers the code itself hard-codes, and every safeguard that keeps the score honest.

The direct answer about "weights": there are no numeric weights in the code. A search for weight across the entire codebase returns zero hits. The score is not a weighted average of the four dimensions — the analysis LLM weighs them qualitatively and issues one holistic credibilityScore. The "weights" that exist are:

  • the 0–100 anchors of each dimension in the prompt (§2) — the rubric the model weighs,
  • the verdict thresholds 80 / 60 / 40 in the panel (§4) — the only hard-coded scoring numbers, and
  • the grounding constraints (§5) that decide what evidence the model may weigh at all.

The model is instructed to score within the article's own regional and political context — the exact prompt opening (utils/api.js, buildAnalysisPrompt):

You are an expert global media bias analyst. You must identify the REGIONAL and POLITICAL
context of the article (e.g. Nigerian, Indian, Brazilian, UK, US, etc.) and evaluate bias
within that local context — do NOT default to a US-centric left-right spectrum.

2. The scoring rubric — every scale and its anchors

All five numbers are 0–100 integers defined by one fixed response schema (RESPONSE_SCHEMA, utils/api.js). The anchors below are quoted verbatim from the schema the model must fill.

FieldScale0 means100 meansDirection
credibilityScore0–100— (no lower anchor given)80+ means mostly neutral/crediblehigher = better
linguisticBias0–100no loaded languageextreme loaded languagehigher = more bias
ideologicalLean0–100perfectly balancedextreme one-sidedhigher = more bias
sentimentPolarity0–100factually neutral toneextreme emotional manipulationhigher = more bias
factualCompleteness0–100all key facts absentall key facts presenthigher = better

Note the polarity split: three dimensions rise with bias, while factualCompleteness rises with quality. credibilityScore is the headline judgment the panel meters; the four dimensions are displayed as separate bars that let you see why.

3. Why it is a rubric, not a formula

The schema fixes the scales and anchors, but the prompt never assigns percentages to the dimensions. When the model emits credibilityScore: 72, that 72 is its holistic weighing of loaded language, one-sidedness, emotional manipulation, and fact coverage — judged against whatever the live coverage search gathered for this story. Two design consequences:

  • Scores are not reproducible arithmetic. The same article can score a few points differently across runs or models. Consistency is pushed down, not eliminated: sampling temperature 0.3, top_p 0.9, an 8192-token budget, and per-model thinking disabled (NVIDIA enable_thinking: false; OpenRouter reasoning models flagged off) so the answer is a straight judgment, not a chain-of-thought drift.
  • Changing a weight means changing the prompt. If you ever want numeric weights (e.g. score = 0.3·linguistic + 0.3·ideological + 0.2·sentiment + 0.2·completeness), that formula does not exist today — it would be added in buildAnalysisPrompt/analyzePage, and the panel's verdict thresholds would stay the consumer.

4. Verdict bands — the only hard-coded scoring numbers

What the code itself decides (verdictBand / setVerdict, sidepanel/sidepanel.js): the raw score is clamped to Math.min(100, Math.max(0, Number(score) || 0)) and mapped to a verdict:

Score rangePanel verdictCSS classMeaning of the band
80–100Mostly Credibleverdict-highMostly neutral, credible reporting; matches the schema's "80+" anchor
60–79Moderate Biasverdict-moderateNoticeable slant in language, framing, or emphasis
40–59Significant Biasverdict-lowClear one-sided framing, loaded language, or emotional manipulation
0–39Highly Biasedverdict-criticalExtreme slant or manipulation; treat claims with strong skepticism

A missing or non-numeric credibilityScore renders as 0 (data.credibilityScore ?? 0) — i.e. the panel fails conservative, never guessing a mid score. The meter fill and needle animate to the clamped percentage; each dimension bar clamps identically.

5. What the model may weigh — grounding constraints

Grounded run (coverage search returned sources). Every omission must be "a fact evident from the entries above — a fact other listed sources report that this article leaves out." Every perspective card must copy the exact URL of a listed source, "character for character. Never invent a URL."
Ungrounded run (search failed → panel shows the ⚠ NO SOURCES badge). The model is told it has NO real sources: perspectives get source/url = N/A, summaries are limited to general framing context, and omissions must come only from gaps evident in the article text itself.
Code-enforced backstop (validatePerspectiveCitations, utils/api.js). Whatever the model wrote, any perspective url that is not literally one of the gathered search results is blanked to N/A — and an outlet name matching no gathered outlet is blanked too, unless its exact URL vouches for the card. Scores can't cite evidence that was never gathered.
